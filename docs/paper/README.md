# Paper draft

**Watchpoint Compaction: A General Repair Mechanism for Silent Context Loss in LLM Agents.** Second full draft, written and compiled 2026-09-23. The first draft ("Recent Is Not Retained") measured two compaction failure modes and two ad hoc, failure-specific fixes; this draft adds the actual proposed method: track any load-bearing statement as a lightweight watchpoint, let compaction run normally, and cheaply check and patch afterward. A first version of that check (ask the model to self-judge, yes or no) failed badly; a second version (make the model restate what it believes, then check with a deterministic keyword match) works, and statistically ties the best existing specialized fix on both failure modes with one general mechanism. See `paper.pdf` for the current draft, `paper.tex` for the source, and `fig4`/`fig5`/`fig6` (still using their original filenames from the analysis script, though they render as Figures 1, 2, 3 in the compiled paper) for its figures.

Status: a strong second draft with real, statistically significant results on cheap open-weight models, including one genuine negative result (the naive self-judgment check) that is itself part of the paper's contribution, not just a design note. Not yet reviewed by anyone else, and not yet run on frontier backbones or a real coding-agent harness.
